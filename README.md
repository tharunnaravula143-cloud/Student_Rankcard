📊 Student Management & Performance Analysis System (Python)

A Python-based console application designed to manage student records and analyze academic performance efficiently.This project allows users to add students, store subject-wise marks, calculate statistics, assign grades, and identify top performers in each subject.

🚀 Features

Add student details (Name, Roll Number, Marks)

Calculate average, highest, and lowest marks

Automatic grade assignment based on average score

Display all students in a well-formatted table

Identify subject-wise toppers with student names

Handles missing or empty data safely

Clean, modular, and beginner-friendly Python code

🛠️ Technologies Used

Python 3

Core concepts: Lists, Dictionaries, Functions, Loops, Conditionals

🎯 Use Cases

Academic mini-project

Python practice for beginners

College lab assignments

Understanding data processing & analysis in Python

▶️ How to Run python main.py

📌 Sample Input

Number of students

Student name

Roll number

Subject marks (space-separated)

📈 Output

Complete student performance report

Subject-wise best marks with topper names
